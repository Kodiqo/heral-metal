# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use
[private vulnerability reporting](../../security/advisories/new) on this repository,
or email the Kodiqo team through the contact details on the Kodiqo organization profile.

We aim to acknowledge reports within a few working days.

## Scope

This is a static website with no server-side code. Relevant reports include exposed
secrets, vulnerable dependencies, and issues in the contact/quote form handling.
